# CountryPeek

CountryPeek is a React application that allows users to search and explore countries using the RestCountries API.

## Features

- Country search
- Region filtering
- Sorting
- Country detail pages
- Dark/light theme
- Favourites system
- Persistent localStorage favourites
- Responsive design

## Live Demo

https://incredible-bombolone-1124fc.netlify.app/

## Tech Stack

- React
- Vite
- React Router
- Context API
- useReducer
- CSS Variables
